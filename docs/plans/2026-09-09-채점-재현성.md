# 채점 재현성 개선

- 상태: 완료
- `.agents`는 현재 읽기 전용이므로 작업 계획·보고서는 `docs`에 기록한다.

## 목표

기존 8개 단계의 항목·배점·확인 기준을 보존하고, 세부 기준별 판정과 점수 환산을 분리한다.
같은 판정이면 같은 점수가 나오도록 하고, 단계별 합성 채점 예시로 판정 경계를 명시한다.

## 작업

- 세부 기준 ID, 건수 기반 판정 스키마, 고정 환산식 및 N/A·중복 감점 규칙 추가.
- 단계별 예시와 공통 만점·부분점수·0점·N/A 예시를 실제 프롬프트에 연결.
- 질문 생성 수·길이의 결정론 검사를 적용하고 저장된 구형 결과 형식 유지.
- 편집본 호환·환산·프롬프트·결정론 검사 테스트, 가능하면 고정 입력 반복 채점 비교.
- 구현 내용·측정 결과·남은 한계를 보고서에 기록.

## 검증 원칙

반복 검증은 기존 평가 결과 파일을 덮어쓰지 않는다. 합성 입력과 보류된 사례를 사용한다.
동일 모델·입력·설정으로 비교하고 실제 호출 실패와 테스트 결과를 구분한다.
예시만으로 의미 판정의 변동이 없어졌다고 주장하지 않는다.

## 완료 근거

전체 테스트 174개 통과, 8개 단계 strict schema 검증, 화면 렌더링 오류 없음.
고정 모델·합성 보류 사례 2개 × 기존/개선 × 5회 = 실제 채점 20회 성공.
세부 결과와 한계는 [개선 보고서](../reports/2026-09-09-채점-재현성-개선.md)에 기록했다.
