# 이슈 관례

## 제목 형식

```
아이콘 Type - 한글 요약
```

- 아이콘을 **생략하지 않습니다**.
- 요약은 한글로, 무엇을 하는지 한 줄로 적습니다.

## 허용 Type·아이콘

| 아이콘 | Type | 쓰임 |
| --- | --- | --- |
| 🐛 | Bug | 잘못된 동작·결함 수정 |
| ✨ | Feature | 새 기능·동작 추가 |
| 🎨 | Refactor | 동작을 바꾸지 않는 구조 개선 |
| 🔧 | Task | 설정·문서·빌드·잡무 등 그 외 작업 |

- 표에 **없는 Type·아이콘은 임의로 만들지 않습니다.** 새 분류가 필요하면 먼저 확인하고,
  확정되면 이 표와 실제 라벨을 함께 갱신합니다.

## 예시

- `🐛 Bug - 채점 결과가 빈 데이터셋에서 0으로 나오는 문제`
- `✨ Feature - 로컬 GUI 에서 평가 실행 버튼 추가`
- `🎨 Refactor - 지표 계산기를 모듈로 분리`
- `🔧 Task - AGENT.md 와 .agents 스캐폴딩 정리`

> 예시의 요약 문구는 형식을 보이기 위한 것이며 실제 백로그가 아닙니다.
