## 결정과 근거

- **Python 3.12 고정**: 로컬에 3.12.3 이 이미 설치돼 있어 다운로드 없이 즉시 사용. 3.14 는
  너무 최신이라 일부 패키지 wheel 호환 리스크가 있어 피함.
- **langfuse 는 v4.14.3 로 해결됨**(SDK v4, OpenTelemetry 기반). env 변수 이름은
  `LANGFUSE_PUBLIC_KEY` / `LANGFUSE_SECRET_KEY` / `LANGFUSE_HOST` 그대로 사용.
- **키는 `SecretStr` + 선택값(Optional)**: 값이 repr·로그에 노출되지 않게 하고, 키가 없어도
  앱은 뜨되 사이드바에서 경고를 띄우도록 함(“실행되는 빈 껍데기” 목표).
- **`app/main.py` 상단 sys.path 부트스트랩**: `streamlit run app/main.py` 는 `app/` 를
  sys.path 에 넣어 `app.config` 패키지 import 가 깨질 수 있어, 프로젝트 루트를 경로에 추가.
- **`.uv-cache/` 를 `.gitignore` 에 추가**(AGENT.md 의 로컬 캐시 규칙).
