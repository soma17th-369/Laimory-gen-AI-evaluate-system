## 결정과 근거

- **langfuse v4 API 표면을 introspection 으로 확인 후 사용**(추측 금지):
  - 목록: `client.api.trace.list(*, page, limit, name, user_id, from_timestamp, to_timestamp, tags, ...)` → `Traces(.data/.meta)`.
  - 상세: `client.api.trace.get(trace_id)` → `TraceWithFullDetails`(관측치·스코어 포함).
  - 필드는 snake_case(`user_id`, `total_cost`, `usage_details`, `start_time` 등). 관측치는 `ObservationsView`.
- **표시 매핑을 client 모듈에 두고 UI 는 얇게**: SDK 버전차에 대비해 전부 `getattr` 로 방어.
- **토큰 수**: `usage.total` 우선, 없으면 `usage_details` 숫자 합.
- **키 취급**: `get_secret_value()` 는 SDK 생성자에만 전달, 로그·화면에 값 미노출. 키 없으면
  버튼 비활성 + 안내(앱은 정상 기동).
