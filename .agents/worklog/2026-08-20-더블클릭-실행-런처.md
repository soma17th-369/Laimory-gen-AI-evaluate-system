# 2026-08-20 — 더블클릭 실행 런처

## 배경

매번 터미널에서 `uv run streamlit run app/main.py` 를 치는 게 번거롭다는 요청. 아이콘 하나로
앱이 뜨고 브라우저까지 열리게 한다.

## 결정

- `scripts/run-app.cmd`(ASCII) → `scripts/run-app.ps1`(UTF-8 **BOM**) 2단 구성.
  - `.cmd` 는 더블클릭 대상이자 실행 정책 우회(`-ExecutionPolicy Bypass`) 래퍼다.
  - `.ps1` 은 한글 메시지를 쓰므로 BOM 이 필요하다. Windows PowerShell 5.1 은 BOM 없는 UTF-8 을
    ANSI 로 읽어 한글이 깨진다.
- **streamlit 을 headless 로 띄우고 브라우저는 런처가 연다.** headless 가 아니면 첫 실행에서
  "Welcome to Streamlit! … Email:" 프롬프트가 stdin 을 기다리며 멈춘다(실제로 이 상태로 서버가
  안 뜨는 걸 재현했다). `.claude/launch.json` 은 원래 `--server.headless true` 라 이 문제를
  겪지 않았던 것.
- 포트가 이미 LISTEN 이면 중복 실행하지 않고 브라우저만 연다(실수로 두 번 눌러도 안전).
- `uv` 는 PATH 우선, 없으면 `%USERPROFILE%\.local\bin\uv.exe` 로 폴백.
- 창을 닫거나 Ctrl+C 하면 종료되도록 자식 프로세스를 `-NoNewWindow` 로 띄우고 `WaitForExit`.
  창 제목에 종료 방법을 적어둔다.

## 변경

- 추가 `scripts/run-app.cmd` · `scripts/run-app.ps1`
- 추가 `assets/app-icon.ico`(+`app-icon.png`) — Pillow 로 생성. 막대 3개 도형이라 16px 에서도 식별된다.
- 바탕화면 바로가기 `Laimory 평가 도구.lnk` 생성(최소화 실행, 위 아이콘). 저장소 밖 산출물이라
  git 에는 없다. 다시 만들려면 `scripts/run-app.cmd` 우클릭 → 바로 가기 만들기.
- `AGENT.md` 실행 섹션에 한 문단 추가.

## 검증

- 콜드 스타트: 런처 실행 → 약 2초 뒤 `http://localhost:8501` HTTP 200, 이메일 프롬프트 없음.
- 중복 실행: 이미 떠 있는 상태에서 다시 실행 → "이미 실행 중입니다. 브라우저만 엽니다" 후 종료.
- 한글 출력이 콘솔에서 깨지지 않는 것 확인.
