## 질문 판정 예시

아래는 합성 예시다. 한 기준 안에서만 통과/실패를 설명하며 다른 항목 점수를 추정하지 않는다.

### 회고 유도: 전체 항목 채점

입력 E1: title='공원 산책', description='공원에서 산책했다', timeOfDay='오후'.
출력 A: '산책하면서 어떤 생각이 들었어요?'
reflection c01·c02·c04 가 1/1 이고 c03 은 무엇을 했는지 빠진 event 가 아니라 0/0 이므로 30점.
경험·생각을 묻고, event 의 활동을 짚었고, 답을 정해 놓지 않았다.

출력 B: '산책하느라 힘드셨죠?'
reflection c04 실패(답을 정해 놓은 질문). c01~c03 은 따로 판정한다.

### 장소 표현은 채점하지 않는다

v3 의 '공원 산책에서 어떤 생각이 들었어요?' 와 v4 의 '이곳에서 걸으며 어떤 생각이 들었어요?' 는
장소를 쓰는 방식만 다르므로 같은 점수다. 입력에 없는 '한강공원' 을 지어내면 event_grounding c01 실패다.

### 근거 없는 전제

같은 입력에 '친구와 산책하며 어떤 생각이 들었어요?' 를 만들면 입력에 없는 사람을 전제하므로
event_grounding c01 실패. 친구를 만났다는 근거가 입력 event 에 있으면 통과다.

### 누락과 길이 경계

입력 E1~E5 중 E5 질문만 비어 있으면 coverage c01·c02 모두 4/5 → 16점.
질문 출력 전체가 비어 있으면 둘 다 0/5 → 0점. 입력이 0개이면 N/A다.
연결된 질문이 정확히 두 개면 해당 event 는 '정확히 1개' 조건 실패다.
expression c02 는 앞뒤 공백을 제거한 Unicode 문자 수로 판정한다. 40자 통과, 41자 실패.
따옴표로 감싼 JSON 표기용 문자는 세지 않고 실제 question 문자열의 공백·문장부호는 센다.
