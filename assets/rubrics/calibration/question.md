## Question Agent 판정 예시

아래는 합성 예시다. 한 기준 안에서만 통과/실패를 설명하며 다른 항목 점수를 추정하지 않는다.

### 회고 유도: 전체 항목 채점

입력 E1: title='공원 산책', description='공원에서 산책했어요', timeOfDay='오후'.
출력 A: '공원 산책에서 어떤 생각이 들었나요?'
reflection c01~c05가 모두 1/1이므로 30점. 경험·생각을 묻고, 사건 단서가 있으며,
주관식이고, 이미 알려진 발생 여부를 재질문하지 않고, 감정이나 원인을 단정하지 않는다.

출력 B: '공원 산책에서 어떤 생각이 들었나요? 예 또는 아니오로만 답해주세요.'
reflection c01=1/1, c02=1/1, c03=0/1, c04=1/1, c05=1/1 → 24점.
c03의 failedRefs=['E1.question']. 단답을 강제한 위반이다.
별도로 expression에서는 한 문장 조건 등 실제 위반을 해당 기준에만 반영한다.

### 근거 없는 전제

같은 입력에 '친구와 산책하며 어떤 생각이 들었나요?'를 생성했다면 입력에 없는 사람을
전제하므로 event_grounding의 해당 기준 실패. 친구를 실제 만났다는 근거가 추가되면 통과.
'누구와 산책했나요?'는 상대를 특정하지는 않지만 이 기준이 요구하는 회고 질문 조건과
이미 입력된 정보 여부를 별도로 확인한다. 두 문장을 같은 환각으로 분류하지 않는다.

### 누락과 길이 경계

입력 E1~E5 중 E5 질문만 비어 있으면 coverage c01,c02 모두 4/5 → 16점.
질문 출력 전체가 비어 있으면 둘 다 0/5 → 0점. 입력이 0개이면 N/A다.
연결된 질문이 정확히 두 개면 해당 event는 '정확히 1개' 조건 실패다.
expression c02는 앞뒤 공백을 제거한 Unicode 문자 수로 판정한다. 40자 통과, 41자 실패.
따옴표로 감싼 JSON 표기용 문자는 세지 않고 실제 question 문자열의 공백·문장부호는 센다.
