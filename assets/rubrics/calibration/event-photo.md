## Photo Event Agent 판정 예시

합성 Vision P1: '탁자 위 커피잔', 사람·행동·감정·방문 목적 정보 없음.
출력 A: '탁자 위에 커피잔이 있어요' → beyond_vision c01=1/1 → 15점.
출력 B: '친구와 즐겁게 커피를 마셨어요' → c01=0/1 → 0점.
사람·감정·행동을 함께 추가했어도 P1 출력 한 단위이므로 실패 1건이며 HALLUCINATION을 남긴다.
주장이 여러 개라는 이유로 total을 임의로 늘리지 않는다.

사진 5개 모두 반영되고 촬영 시각도 읽었으면 photo_coverage c01=5/5 → 20점.
P5만 누락됐다면 4/5 → 16점. 사진 입력이 없으면 N/A다.

description이 유사한 P1,P2의 촬영 시각 차이가 정확히 10분이면 시간 조건을 충족한다.
10분 1초면 해당 cluster 병합 시간 조건을 충족하지 않는다. 시간만 가깝고 description이
유사하지 않은 사진은 시간 조건만으로 병합을 정당화하지 않는다.
