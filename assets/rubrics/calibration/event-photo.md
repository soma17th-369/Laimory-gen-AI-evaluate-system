## 사진 해석 판정 예시

합성 Vision P1: '탁자 위 국물 요리와 만두', 사람 없음. P2: '강변 노을 풍경'. P3: 설명 없음.
출력 A(v3 모양): candidate '점심으로 국물 요리와 만두를 먹었다'(P1), '강변에서 노을을 봤다'(P2).
출력 B(v4 모양): 단서 P1 activity='국물 요리와 만두를 먹음', P2 activity='노을을 봄'.
A·B 는 출력 모양만 다르므로 같은 점수다. 모양 차이로 기준을 실패시키지 않는다.

action c03: '먹었다'는 장면에서 추론한 행동이라 허용된다 → 통과. P1 을 '친구와 즐겁게 먹었다'로
쓰면 사람·감정을 지어냈으므로 no_fabrication c01 실패이고 HALLUCINATION 을 남긴다. 같은 출력
한 단위이므로 실패는 1건이다.

coverage c01: P1·P2 가 모두 결과에서 확인되면 2/2. P3 은 설명이 없어 c01 의 단위가 아니다.
P3 에 '카페에서 공부했다'를 만들면 coverage c03 실패, 결과에서 뺐으면 통과다.

specificity c01: P1 을 '식사했다'로만 쓰면 무슨 음식인지가 빠져 실패다.
