## Notification Event Agent 판정 예시

합성 입력 N1: '내일 저녁 식당 예약이 확정되었습니다', 오늘 방문 근거 없음.
출력 A: 내일의 예약 사실을 보존 → reservation의 미래 예약 처리 조건 통과.
출력 B: 오늘 식당에서 저녁을 먹었다고 확정 → 같은 조건 실패, N1 또는 출력 경로를 남긴다.
내일과 오늘을 바꾼 위반은 표현이 자연스럽더라도 통과시키지 않는다.

입력 N2: 친구에게서 메시지를 수신했으며 사용자 발신·답장 근거 없음.
수신 사실·내용을 보존하면 해당 근거 조건 통과. '서로 대화를 나눴다'고 확정하면
messenger의 양방향 대화 근거 조건 실패다. 사용자 답장 근거가 함께 있으면 이 위반은 아니다.

결제 알림이 하나도 없으면 payment 기준은 0/0. 결제 알림이 있지만 필요한 결과를 모두
누락하면 그 입력은 실패 단위다. 개인정보를 출력하지 않았다는 이유로 noise_privacy의
노출 금지 조건을 N/A로 만들지 않는다. 해당 출력이 있으면 노출 여부를 확인해 통과 처리한다.
