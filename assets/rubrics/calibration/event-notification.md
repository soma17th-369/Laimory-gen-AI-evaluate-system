## 알림 해석 판정 예시

합성 입력 N1: '내일 저녁 식당 예약이 확정되었습니다', 오늘 방문 근거 없음.
내일의 예약으로 남기면 schedule_date c01·c03 통과. 오늘 식당에서 저녁을 먹었다고 쓰면 c01 실패이고
N1 을 failedRefs 에 남긴다. 표현이 자연스러워도 날짜를 바꾼 것은 통과시키지 않는다.

입력 N2: 친구 '민수'가 보낸 메시지. 사용자 답장 근거 없음.
'민수에게서 주말 계획 메시지를 받았다'는 conversation c01 통과. '민수와 이야기를 나눴다'로 쓰면
c01 실패다. 이 문장 꼴이 v3 프롬프트의 문장 형식이어도 받은 메시지를 대화로 바꾼 것은 실패로 센다.

입력 N3: 쇼핑 앱 광고. v3 가 fragment 로 남기고 candidate 로 올리지 않았거나, v4 가 단서로 내지 않았으면
noise c01 통과. 광고를 하루의 일(candidate·단서)로 올리면 실패다.

결제 알림이 하나도 없으면 결제에만 걸리는 단위는 없다. 개인정보를 옮기지 않았다는 이유로 privacy c01 을
N/A 로 만들지 않는다. 출력이 있으면 노출 여부를 확인해 통과로 센다.
