## Timeline 초안 판정 예시

합성 입력: C1 은 오늘 회의 일정뿐이고 참석·이동·사진·메시지 근거가 없다.
'프로젝트 회의 일정이 있었다'는 source_use c04 통과. '프로젝트 회의에 참석했다'는 참석을 확정한
근거가 없어 c04 실패이고 HALLUCINATION 이다. 참석을 뒷받침하는 독립 근거가 있으면 실패가 아니다.

사진 P1 을 E1 과 E2 에 모두 붙였다면 source_use c01 은 P1 한 단위 0/1 이다. 두 event 에 있다고
total 을 2로 늘리지 않는다. 한 곳에만 맞게 붙었으면 1/1, 빠졌으면 0/1 이다.

title '노을 구경'(v3)과 '노을을 봄'(v4)은 끝 모양만 다르므로 writing c02 를 똑같이 통과한다.
'저녁과 밤 산책' 은 때 둘을 이었으므로 어느 버전이든 c02 실패다.

v4 draft 의 place 가 null 이고 placeCandidates 첫 후보가 사진 속 상호와 같으면 place c01 통과다.
v3 draft 의 place 가 근거에 없는 '스타카페'이면 place c02 실패다.

같은 동네라는 이유만으로 장소·활동·사람이 모두 다른 두 체류를 한 event 로 합쳤으면 composition c03 실패.
같은 입력 묶음을 나열 순서만 바꿔 여러 번 실패로 세지 않는다.
