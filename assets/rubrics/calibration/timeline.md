## Timeline Agent 판정 예시

합성 입력: C1은 오늘 회의 캘린더 일정뿐이며 참석·이동·사진·메시지 근거가 없다.
출력 A: '회의가 예정돼 있었어요' → 일정과 참석을 구별한 주장이다.
출력 B: '회의에 참석했어요' → 참석을 확정한 근거가 없으므로 해당 근거 조건 실패 및
HALLUCINATION. 실제 참석을 뒷받침하는 독립 근거가 추가되면 같은 완료형이 자동 실패는 아니다.

Photo P1을 E1과 E2의 sourceRefs에 각각 넣었다면 source_final의 Photo 단일 귀속 기준은
P1 한 단위 0/1. 두 이벤트에 있으므로 total=2로 늘리지 않는다. 한 곳에만 올바르게 연결되면
1/1이다. 누락이면 0/1이다. 이 비율은 해당 세부 기준이며 source_final 항목 전체 점수는
다른 적용 기준 통과율과 함께 계산한다.

서로 시간만 겹치고 장소·사람·활동이 모두 다른 두 후보를 병합하면 관련 병합 기준 실패.
동일 사건을 지지하는 원문 조건까지 충족하면 통과다. 동일 입력 묶음을 나열 순서만 바꿔
여러 병합 실패로 세지 않는다.

시간 항목의 'Calendar startAt·endAt이 window의 startTime·endTime과'는 원문이 미완성이다.
비교 연산을 추측하지 않고 해당 기준은 0/0, reason='기준 모호: Calendar/window 비교 문장 미완성'.
완성된 별도 window 준수 기준은 정상 판정한다.
