## Location Event Agent 판정 예시

합성 입력 M1: A에서 B로 이어진 하나의 MOVEMENT. 출력에 A→B 이동이 한 번 보존되면
movement_flow의 해당 이동 보존 기준은 1/1. B 도착이 사라지면 0/1이고 failedRefs=['M1'].
연결된 한 이동을 분할했을 때는 M1을 여러 개의 실패 입력으로 중복 세지 않는다.

입력 S1: 장소 유형 '카페', STAY 1건, 활동·동행·방문 목적 없음.
출력 A: 카페에 머묾 → 확인되는 체류·장소 주장 통과.
출력 B: 카페에서 친구와 시험 공부를 함 → place_activity의 근거 없는 활동·인물 확정 기준 실패.
공부와 동행을 모두 추가했어도 같은 기준·출력 단위에서는 실패 1건. HALLUCINATION은 남긴다.

STAY 입력이 0건이면 체류 조건은 0/0. STAY가 있으나 출력이 누락되면 해당 필수 반영
조건의 분모에 남긴다. 명시된 제외 조건에 맞는 체류를 제외한 경우는 누락 실패로 세지 않는다.
