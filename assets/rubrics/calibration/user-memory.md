## User Memory Agent 판정 예시

합성 기존 preferences='차를 좋아함'. 최신 memo='이제 차보다 커피를 좋아한다'.
갱신 결과가 최신 선호로 바뀌고 관련 없는 기존 관계 정보는 보존됐다면 update_method의
충돌 교체·미변경 field 보존 기준 통과. 관계 정보를 근거 없이 지웠다면 보존 기준 실패.

입력에 '동생은 간호사다'만 있는데 사용자의 basicProfile에 '간호사'를 넣으면
field_confusion의 주변 사람 직업 혼동 기준 실패. 관계 인물의 직업과 사용자의 직업을 구분한다.

memo가 없고 서로 다른 날짜의 동일 성향 근거가 2회 미만인데 personality를 새로 바꾸면
provenance의 성향 변경 제한 기준 실패. field_placement의 추론 허용 표현은 이 제한을
해제하지 않는다. 기존 성향을 유지하면 이 제한 조건 통과다.

자연어 field 500자는 size_privacy의 길이 조건 통과, 501자는 실패다.
기준은 LLM 확인 원문의 500자이며 사용하지 않는 '코드 측정' 설명의 200자로 바꾸지 않는다.
전화번호 등이 노출되지 않은 출력 프로필은 개인정보 금지 기준 통과이며 N/A가 아니다.
